# Data Sources

VeriflowAPI aggregates and normalizes data from multiple authoritative government sources. This page explains what each source covers, how frequently data is refreshed, and what happens when a source is temporarily unavailable.

## Federal Sources

These sources are checked on every verification request regardless of state.

### NPPES NPI Registry

The National Plan and Provider Enumeration System is the federal database of all healthcare providers who have been assigned a National Provider Identifier.

| Detail | Value |
|---|---|
| Coverage | All 50 US states |
| Data includes | Name, NPI, taxonomy, practice address, credential status |
| Refresh frequency | Daily bulk download |
| Cache TTL | 24 hours |
| Managed by | Centers for Medicare & Medicaid Services (CMS) |

The NPPES database is the foundation of every verification. Even when a state board is temporarily unavailable, NPI data ensures you always receive a meaningful baseline response.

### OIG Exclusion List

The Office of Inspector General maintains a list of individuals and entities excluded from participation in federal healthcare programs (Medicare, Medicaid, etc.). Hiring or contracting with an excluded provider can result in significant civil penalties.

| Detail | Value |
|---|---|
| Coverage | All 50 US states |
| Data includes | Name, NPI, exclusion type, exclusion date, reinstatement date |
| Refresh frequency | Monthly official update, checked every 12 hours |
| Cache TTL | 12 hours |
| Managed by | HHS Office of Inspector General |

If `oig_excluded` is `true`, the provider must not be employed or contracted by any entity receiving federal healthcare funding. This is a hard disqualifier in most onboarding workflows.

## State Sources — Live

Deep state license data is available for **twenty-three states** today. Texas, New York, Pennsylvania, Ohio, and Michigan are live per-query scrapes; the rest are full mirrors (refreshed daily, or monthly for California). Any other state returns `status: "unsupported_state"` on live keys — we never fabricate data we don't have.

### New York Office of the Professions

| Detail | Value |
|---|---|
| Access | Live per-query search of the state verification API, 24-hour per-query cache |
| License types | Physicians, psychologists, social workers, mental health counselors, marriage & family therapists, PT, OT, SLP, and more |

New York licenses do not "expire"; the triennial **registration** does. A currently registered licensee returns `status: "active"`; a lapsed registration returns `status: "expired"`. ### Pennsylvania Licensing System (PALS)

| Detail | Value |
|---|---|
| Access | Live per-query search of the PALS verification service, 24-hour per-query cache |
| License types | Physicians (MD/DO), psychologists, social workers, marriage & family therapists, professional counselors, PT, OT, SLP |
| Data includes | License number, license type, board, status, issue date, expiry, disciplinary actions |

PALS lists every license a person holds (for example an expired training permit alongside an active MD license); we resolve to the active, highest-tier license. Licensee contact details returned by the state are never stored.

### Ohio eLicense

| Detail | Value |
|---|---|
| Access | Live per-query search of the eLicense Ohio verification service, 24-hour per-query cache |
| License types | Physicians (MD/DO), psychologists, social workers, professional counselors, marriage & family therapists, PT, OT, SLP |
| Data includes | License number, license type, board, status and sub-status, issue and expiry dates, board-action flag and summary |

Ohio's top-level status is coarse (Active / Inactive / Closed); the informative detail is the sub-status (Expired, Lapsed, Suspended, Retired, ...), which we normalize. eLicense Ohio states that the Joint Commission and NCQA accept its online status as primary-source verification. Address and alias data returned by the state are never stored.

### Delaware Division of Professional Regulation (DPR)

| Detail | Value |
|---|---|
| Access | Daily mirror of Delaware's consolidated licence dataset, plus the published disciplinary register |
| License types | Medical practice (MD/DO/PA), psychology, social work, mental health counselling, physical therapy and athletic training, occupational therapy, speech and hearing |
| Data includes | License number, license type, profession, status, issue date, expiry date, disciplinary action |

Delaware publishes its whole licence database as open data, refreshed every morning. The licence file has a disciplinary column of its own, but it reads "no" on every row in the state including revoked licences, so we ignore it and join the state's separate disciplinary register on the licence number instead. That distinction matters: several hundred Delaware licensees are currently active **and** carry a board action, which the licence file alone would have reported as clean. Delaware publishes no NPI, and no street address, email or phone appears in either dataset.

### New Jersey Division of Consumer Affairs (DCA)

| Detail | Value |
|---|---|
| Access | Daily mirror of the NJ DCA bulk licence rosters (eight profession downloads) |
| License types | Physicians (MD/DO) and PAs, psychologists, social workers, professional counselors, marriage & family therapists, PT, OT, speech-language pathologists and audiologists |
| Data includes | License number, license type, profession, status, issue date, expiry date |

New Jersey publishes a roster download rather than requiring a per-name lookup, so the whole state is mirrored daily. The roster carries status and expiry but **no disciplinary history column**. We report a sanction where the state encodes one in the licence status itself, such as a suspension or a voluntary surrender, but a board action taken against a licence that is otherwise current will not appear. Roughly one row in seven is an application that never became a licence and carries no licence number; those are dropped rather than counted as licensees. New Jersey publishes no NPI. Address and email data in the roster is never stored.

### Michigan LARA (MiPLUS)

| Detail | Value |
|---|---|
| Access | Live per-query search of LARA's public MiPLUS licensee portal, 24-hour per-query cache |
| License types | Medical doctors, osteopathic physicians, psychologists, master's and bachelor's social workers, professional counselors, marriage & family therapists, PT, OT, SLP |
| Data includes | License number, license type, status, issue and expiry dates, current board conditions |

Michigan publishes no bulk licensee file, so the portal is queried at verification time. Two limits are worth planning around. Michigan labels a license whose expiry has passed but which is still inside the renewal window as "Active - In Late Renewal"; we report that as **expired**, because the date has passed and practice is not authorized. And LARA publishes no NPI anywhere, so Michigan resolves on name alone. Discipline appears as current conditions such as probation or suspension, without the order narrative, which LARA issues separately in monthly disciplinary reports. Address data returned by the state is never stored.

### Massachusetts (MA)

| Detail | Value |
|---|---|
| Access | Live per-query lookup against the Board of Registration in Medicine, 24-hour per-query cache |
| License types | Physicians (MD/DO) and physician assistants |
| Data includes | License number, status, issue and expiry dates, NPI, disciplinary actions in four categories, malpractice history |

Massachusetts is the first live state that publishes NPI, so a request carrying an NPI returns `high` match confidence. The disciplinary flag is raised by any board or facility action, criminal conviction, or malpractice record, and the four categories are kept separately in the raw payload. Both names are matched loosely by the board's search, so we require an exact surname before confirming anyone. Physicians only: the boards for the other professions were not reachable from our infrastructure.

### Vermont (VT)

| Detail | Value |
|---|---|
| Access | Daily mirror of the Board of Medical Practice public roster |
| License types | Physicians (MD/DO), physician assistants, podiatrists, anesthesiologist assistants |
| Data includes | License number, license type, status, issue date, expiry date, sanction status |

The roster carries 35 distinct status strings and we map every one explicitly. A licence the board marks inoperable has no practice agreement behind it and is reported as inactive, not active. Sanctions (reprimand, conditions, surrender, suspension, revocation) are encoded in the status and raise the disciplinary flag; the roster's notes column is not a discipline signal. Vermont's psychology, social work, counselling and therapy professions are licensed by a separate office and are not covered. No NPI.

### Maryland (MD)

| Detail | Value |
|---|---|
| Access | Monthly mirror of the Board of Physicians public rosters (refreshed on the 1st of each month) |
| License types | Physicians (MD/DO), physician assistants and other allied health professions licensed by the board |

The physician roster lists **current licensees only**: an expired, suspended or revoked physician is absent from it rather than listed with that status, so a Maryland `not_found` is not evidence that someone was never licensed. ## What happens when a source is down

Government websites experience downtime — planned maintenance, traffic spikes, infrastructure migrations. VeriflowAPI is architected to handle this gracefully.

When a source is unavailable during a request:

1. VeriflowAPI serves the most recent cached data for that source
2. The response includes `"source_live": false` and `"cached": true`
3. The `cache_expires_at` field tells you when fresh data will next be fetched
4. Our monitoring system detects the outage and begins retry attempts automatically

If there is **no** cached data for that provider, we do not guess. The response returns `status: "source_unavailable"` with `verified: false`, which is deliberately distinct from `not_found`. `not_found` means the board answered and holds no matching record; `source_unavailable` means we could not ask it. Treat the first as an exception to investigate and the second as a retry. The federal signals in the same response (NPPES identity and OIG exclusion) are still valid.

This approach ensures our 99.9% uptime SLA holds even when individual government sites experience extended downtime.

You can always check current source availability at **[veriflowapi.com/status](https://veriflowapi.com/status.html)**.

## Remaining states

For states not yet mirrored, VeriflowAPI returns NPPES and OIG data, which covers federal credential status nationwide. State-level license status for additional states is added based on demand.

If you have an urgent need for a specific state, email support@veriflowapi.com — we prioritize state additions based on customer demand.
