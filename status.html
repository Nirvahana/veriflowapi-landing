How to read this page

Operational

The source answered normally on the last check. Mirrored sources also show the date of the data we hold.

Degraded

Reachable but not fully healthy — usually data older than expected, or an intermittent error. A single transient blip shows here rather than as an outage.

Down

The source failed repeated checks. Verifications for it fall back to the most recent cached result, flagged source_live: false.

When a source is unavailable we serve the most recent cached data and mark it clearly in the response rather than guessing, and a state we do not cover always returns unsupported_state. See coverage for what each source includes.
